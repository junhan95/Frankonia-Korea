> **용도**: Frankonia Korea 웹사이트 리뉴얼 및 모든 디자인 산출물의 **단일 기준 문서**.
> 이후 제작되는 모든 페이지·배너·문서의 디자인 요소는 본 문서를 참조하여 작성한다.

## 1. 컬러 시스템

CyberShield 사이트의 `:root` CSS 변수에서 그대로 추출한 값.

### 1.1 브랜드 컬러

| 토큰 | HEX | 용도 |
|---|---|---|
| `--primary` / `--red` | `#E60000` | 브랜드 레드. 주요 CTA 버튼, 아이브로우(섹션 라벨), 강조 텍스트, 번호 마커, Contact 섹션 배경 |
| `--primary-dark` | `#BD0000` | 레드 호버/눌림 상태 |
| `--ink` | `#25282B` | 다크 차콜. 헤더·다크 섹션·푸터 배경, 밝은 배경에서의 제목 색 |

### 1.2 텍스트 컬러

| 토큰 | HEX | 용도 |
|---|---|---|
| `--ink` | `#25282B` | 제목 (밝은 배경 위) |
| `--body-dark` | `#4A4D50` | 본문 강조 |
| `--body-text` / `--muted` | `#7E7E7E` | 기본 본문. 표 데이터 셀, 설명 텍스트 |
| `--mute` | `#BEBEBE` | 비활성/보조 텍스트, 카드 테두리 |
| `#FFFFFF` | `#FFFFFF` | 다크·레드 배경 위 텍스트 |

### 1.3 배경·라인 컬러

| 토큰 | HEX | 용도 |
|---|---|---|
| `--canvas` / `--paper` | `#FFFFFF` | 기본 섹션 배경 |
| `--canvas-soft` | `#F2F2F2` | 소프트 그레이 섹션·카드 배경 (비교표, Process, Company 섹션) |
| `--line` | `#D9D9D9` | 헤어라인 구분선 (0.8px), 표 행 구분선 |
| `--ink` | `#25282B` | 다크 섹션 배경 (히어로, 위협/감쇠 성능 섹션, 컷어웨이, 푸터) |
| `--primary` | `#E60000` | **Contact(문의) 섹션은 레드 풀배경** + 흰 텍스트 |

### 1.4 섹션 배경 리듬 (실측 순서)

다크 → 화이트 → 다크가 교차하며, 마지막 문의 섹션만 레드로 강하게 마무리하는 구성.

```
히어로(#25282B) → 대상고객(#FFF) → Why(#FFF) → 위협(#25282B) → 솔루션(#FFF)
→ 컷어웨이(#25282B) → 비교표(#F2F2F2) → 에코시스템(#FFF) → 검증(#FFF)
→ 감쇠성능(#25282B) → 적용분야(#FFF) → 시나리오(#FFF) → 프로세스(#F2F2F2)
→ 책임범위(#FFF) → 회사소개(#F2F2F2) → FAQ(#FFF) → Contact(#E60000) → 푸터(#25282B)
```

## 2. 타이포그래피

### 2.1 폰트 패밀리

```css
font-family: Inter, "Noto Sans KR", "Helvetica Neue", Arial, sans-serif;
```

- 영문: **Inter** / 한국어: **Noto Sans KR** (다국어 공통 스택 — KO/EN/DE 모두 동일)
- 별도 세리프·디스플레이 폰트 없음. 전체가 단일 산세리프 체계.

### 2.2 타입 스케일 (데스크톱 1440px 기준 실측)

| 요소 | 크기 | 굵기 | 행간 | 기타 |
|---|---|---|---|---|
| H1 (히어로) | 66px | **800 (ExtraBold)** | 1.04 (68.6px) | **대문자(uppercase)**, 자간 -1px, 흰색. 핵심 구절만 레드(`#E60000`)로 강조 |
| H2 (섹션 제목) | 48px (다크 배경 44px) | **300 (Light)** | 1.1 (52.8px) | 문장형(대소문자 그대로), `#25282B` / 다크 배경에선 흰색 |
| H3 (카드 제목) | 20px | 700 | 1.3 (26px) | `#25282B` |
| 본문 | 16px | 400 | 1.5 (24px) | `#7E7E7E` |
| 아이브로우(섹션 라벨) | 13~14px | 700 | — | **레드(#E60000), 대문자, 자간 확대**. 모든 섹션 제목 위에 배치 |
| 표 헤더(th) | 12px | 600 | — | 대문자, `#7E7E7E`, 배경 투명 |
| 표 데이터(td) | 15px | 400 | — | `#7E7E7E`, 행 하단 0.8px `#D9D9D9` 라인 |
| 번호 라벨 (01/02/03) | 12~13px | 800 | — | 레드, 컬럼형 리스트의 번호 |

### 2.3 타이포그래피 핵심 규칙

1. **초대형 헤드라인은 ExtraBold(800) + 대문자**, **섹션 제목은 Light(300)** — 굵기 대비가 이 사이트 아이덴티티의 핵심.
2. 문장 중 강조는 색(레드)으로만 처리, 밑줄·이탤릭 사용 안 함.
3. 본문은 중간 회색(#7E7E7E)으로 낮은 대비 유지 → 제목·CTA가 상대적으로 도드라짐.

## 3. 버튼·인터랙션 요소

### 3.1 버튼 (실측)

| 종류 | 스타일 |
|---|---|
| Primary CTA | 배경 `#E60000`, 흰 텍스트, **완전한 필(pill) 형태 `border-radius: 60px`**, 굵기 400(굵지 않음), 패딩 12px 26px (헤더용 소형: 9px 20px, 16px) |
| Secondary | 투명 배경 + 0.8px 아웃라인(다크 배경 위: `rgba(255,255,255,.45)` 흰 테두리), 흰 텍스트, 동일한 필 형태 |
| 호버 | Primary → `#BD0000` |
| 화살표 글리프 | CTA 텍스트 뒤에 `↗` (외부/이동) 또는 `↓` (스크롤 유도) 부착 — 아이콘 폰트가 아닌 텍스트 글리프 |

```css
--pill: 60px;      /* 버튼 radius */
--pill-md: 32px;   /* 중형 요소 radius */
--radius: 6px;     /* 카드 radius */
```

### 3.2 번호 마커 (인터랙티브 다이어그램)

- 원형(50%), 배경 `#E60000`, 흰 숫자(12px/800), 테두리 1.6px `rgba(255,255,255,.9)`
- 컷어웨이 렌더 위 21개 포인트로 사용 — 제품 구성요소 지시용

### 3.3 언어 스위처

- 헤더 우측, 필 형태 아웃라인 버튼 `EN ▾` 드롭다운 (EN / Deutsch / 한국어)
- 13px / 700, 다크 배경 위 흰 텍스트 + `rgba(255,255,255,.45)` 테두리

## 4. 레이아웃·구조

### 4.1 기본 골격

| 항목 | 값 |
|---|---|
| 헤더 | **sticky**, 높이 70~76px, 배경 `#25282B`(불투명), 하단에 레드 프로그레스/포인트 라인 |
| 헤더 구성 | 좌: Frankonia 로고(레드 매듭 심볼) + 세로 구분선 + CYBERSHIELD 워드마크 / 우: 메뉴 6개 + 언어 + 레드 CTA |
| 섹션 패딩 | **상하 120px** (히어로 70px, 일부 0) — 여백이 매우 넉넉한 구성 |
| 콘텐츠 폭 | 약 1,200px 컨테이너 (1440 뷰포트에서 좌우 대칭 마진) |
| 카드 | 배경 `#F2F2F2` 또는 흰색, radius 6px, 테두리 0.8px `#BEBEBE`, 그림자 거의 없음 (플랫) |

### 4.2 반복 레이아웃 패턴

1. **아이브로우 + 대형 제목**: 레드 대문자 라벨 → Light 48px 제목 → (설명 문단). 모든 섹션 공통 도입부.
2. **번호형 3~4컬럼**: 상단 헤어라인(0.8px #D9D9D9) + 레드 번호(01/02/03) + 볼드 소제목(20px) + 회색 본문. 컬럼 사이 세로 헤어라인.
3. **좌 레드 보더 콜아웃**: `#F2F2F2` 배경 박스 + 좌측 레드 세로 라인 + 좌:제목/우:본문 2컬럼. 핵심 메시지 요약용.
4. **좌 텍스트 + 우 이미지(또는 리스트)** 2분할: 히어로·컷어웨이 등.
5. **헤어라인 리스트**: 행마다 하단 0.8px 라인, 좌측 회색 번호 + 항목명. (컷어웨이 부품 리스트 등)
6. **비교/성능 표**: 테두리 없는 미니멀 표 — th 대문자 12px 회색, 행 구분 0.8px 라인만.

### 4.3 이미지·그래픽 스타일

- **3D 산업 렌더링**(웜그레이 톤의 시설 컷어웨이, 흰 배경) + **실사(webp)**: 설비 항공샷, 기술자 작업 컷
- 히어로: 루프 영상(mp4) 또는 대형 렌더 이미지, 흰 카드 프레임 안에 배치
- 일러스트·아이콘은 최소화 — 사진/렌더와 타이포그래피가 주인공
- 로고: `frankonia-logo.svg` — 레드 매듭 심볼 + FRANKONIA 워드마크

### 4.4 모션

- 스크롤 진입 시 요소 페이드/슬라이드 인 (`reveal` → `is-in` 클래스 방식)
- 히어로 배경 영상 루프
- 과도한 패럴랙스·화려한 효과 없음. 절제된 등장 애니메이션만.

## 5. 톤 & 무드 요약

- **키워드**: 독일 엔지니어링, 정밀·검증(Verified, not assumed), 하이엔드 B2B, 절제된 위엄
- 화이트 여백 중심 + 다크 섹션 대비 + 단일 레드 포인트 — **3색 이상 쓰지 않음**
- 곡선 요소는 버튼(필)과 번호 마커뿐, 나머지는 직선·헤어라인
- 카피 스타일: 짧은 단정형 문장, 마침표로 끝나는 강한 선언 ("Contain the signal.")

## 6. 복사용 디자인 토큰 (CSS)

```css
:root {
  /* Color */
  --primary: #e60000;
  --primary-dark: #bd0000;
  --ink: #25282b;
  --body-dark: #4a4d50;
  --body-text: #7e7e7e;
  --mute: #bebebe;
  --line: #d9d9d9;
  --canvas: #ffffff;
  --canvas-soft: #f2f2f2;

  /* Radius */
  --pill: 60px;      /* 버튼 */
  --pill-md: 32px;
  --radius: 6px;     /* 카드 */

  /* Type */
  --font: Inter, "Noto Sans KR", "Helvetica Neue", Arial, sans-serif;
  /* H1: 66px/800/uppercase/ls -1px — 핵심 구절만 var(--primary) */
  /* H2: 48px/300 */
  /* H3: 20px/700 */
  /* Body: 16px/400, lh 1.5, color var(--body-text) */
  /* Eyebrow: 13px/700/uppercase, color var(--primary), ls +1.5px */

  /* Layout */
  --section-pad: 120px;
  --container: 1200px;
  --hairline: 0.8px solid var(--line);
}
```

## 7. Frankonia Korea 사이트 적용 규칙

1. 랜딩페이지를 포함한 **모든 신규 페이지는 본 문서의 토큰·패턴을 사용**한다. 임의 색상(네이비 등) 사용 금지.
2. 레드는 `#E60000` 단일 값만 사용 (본사 구형 레드·임의 레드 변형 금지).
3. 한국어 본문도 동일 스택(Noto Sans KR)으로, 타입 스케일은 데스크톱 기준을 유지하되 한국어 특성상 H1 자간은 -1px 대신 -0.5~0px로 완화 가능.
4. CyberShield 메뉴/카드의 링크는 `https://www.frankonia-cybershield.com/` (새 창, `rel="noopener"`).
5. 문의(Contact) 섹션은 레드 풀배경 패턴을 따른다. 푸터는 `#25282B`.
6. 버튼 문구 끝 화살표 글리프(`↗`, `↓`, `→`) 관례를 유지한다.
